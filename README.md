# Banco de Dados — Exercícios e Projeto Fluxo

Repositório destinado a armazenar e organizar as atividades desenvolvidas durante as aulas de **Banco de Dados e SQL**.

Aqui serão mantidos os exercícios realizados ao longo da disciplina, permitindo acompanhar minha evolução e manter os arquivos disponíveis para acesso em diferentes dispositivos.

Além das atividades das aulas, o repositório contém o **Fluxo**, meu projeto principal, cuja estrutura de banco de dados será utilizada como base para o trabalho final da disciplina.
